# SideLine v0.1.0

**Your tasks, right beside your work.**

The first downloadable release of SideLine: an offline Windows to-do sidebar built with Tauri 2, Rust and plain JavaScript.

## Download

Download **`Sideline-v0.1.0-windows-x64.zip`**, extract it and run `Sideline.exe`. No application installer is required. A supported x64 Windows environment and [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) are required.

**The app interface is currently Chinese.** English documentation is available; an English UI is not included in this release.

## Highlights

- Left/right screen-edge docking, optional always-on-top and click-to-expand collapse.
- Windows AppBar space reservation for maximized windows and foreground full-screen detection.
- Drag-to-reorder pending tasks, editable task text and multiple notes per task.
- A collapsible completed section, deletion undo and Chinese IME input handling.
- Local JSON storage, serialized saves, atomic file replacement, backups and explicit recovery controls.
- Preserve unsaved edits before reloading externally modified files.
- Remember docking, collapsed state, always-on-top and completed-section preferences.

## Validation

- Windows MSVC release build completed; transparent PNG icon resources restored after compilation.
- All 19 Rust storage/file-operation tests passed.
- Four Microsoft Edge browser regression suites passed using synthetic tasks and mocked IPC.
- Native smoke tests passed on a separately identified QA build from the same application source: startup layout, legacy-data loading, save/backup, restart persistence and AppBar work-area restoration.
- The downloadable executable is the **production** build, not the QA build. Native interactive QA results are not a claim of testing every Windows/display configuration.

## Data and upgrade notes

- Tasks and preferences are stored in `%APPDATA%\com.yan.sideline\`, not beside the executable.
- Quit an existing SideLine instance before replacing its executable. Back up the application-data directory before upgrading or moving to another computer.
- This package does not include personal tasks, application-data backups, browser profiles or development dependencies.

## Known limitations and security

- Windows x64 only; the interface is Chinese. No cloud sync, reminders or global shortcuts.
- AppBar registration/removal can cause Windows to rearrange desktop icons. Display scaling, multi-monitor layouts and full-screen behavior may vary.
- The executable is not code-signed. Windows may show a reputation or security warning. Check the source and checksum rather than disabling security protections.
- Compare `Get-FileHash .\Sideline-v0.1.0-windows-x64.zip -Algorithm SHA256` with the ZIP entry in `SHA256SUMS.txt`. Checksums verify file integrity, not publisher identity.

Please [report issues](https://github.com/lat1bulate/SideLine/issues) with your Windows version, scaling, monitor layout and reproduction steps. Remove personal information from screenshots and logs.
